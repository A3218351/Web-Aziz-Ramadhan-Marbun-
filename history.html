Sejarah HTML & Coding

Dari satu ilmuwan, lahirlah teknologi yang mengubah dunia.

Para Penemu

Tim Berners-Lee — Penemu HTML

Pada tahun 1991, Tim Berners-Lee bekerja di laboratorium fisika CERN di Swiss. Ia membuat HTML agar para ilmuwan bisa berbagi dokumen lewat internet. Dari situlah World Wide Web (WWW) lahir!

Ada Lovelace — Programmer Pertama

Jauh sebelum ada komputer modern, Ada Lovelace (1815–1852) sudah menulis algoritma pertama di dunia. Ia dianggap sebagai programmer pertama dalam sejarah — dan ia adalah seorang wanita!

aziz ramadhan — Bapak Ilmu Komputer

Alan Turing adalah matematikawan yang meletakkan dasar teori komputer modern. Konsepnya menjadi pondasi cara kerja komputer hingga hari ini.

Timeline HTML

1991

HTML pertama kali diperkenalkan oleh Tim Berners-Lee. Website pertama di dunia pun dibuat!

1995

HTML 2.0 resmi distandarisasi. Mulai ada form dan tabel.

1997

HTML 4.0 hadir dengan dukungan CSS dan JavaScript. Website jadi makin cantik!

2014

HTML5 resmi menjadi standar dunia. Inilah versi yang kita pakai sampai sekarang!

Fakta Unik

  • Asal kata "bug": Istilah ini berasal dari tahun 1947, saat ngengat sungguhan nyangkut di dalam komputer!
  • HTML bukan bahasa pemrograman. HTML adalah Markup Language — tugasnya hanya menyusun struktur halaman.
  • Berners-Lee tidak mematenkan temuannya. Ia memberikan WWW secara gratis untuk seluruh dunia!
